\begin{frame}{Appendix: measures and protocol decisions}

\begin{itemize}
\item Cognitive load: Extraneous (5 questions), Intrinsic (5) and Germane (7), 9-point Likert scale \citep{krieglstein2023}
\item General Extended Technology Acceptance Model for
E-Learning (GETAMEL, only in pilot study): \citep{abdullah2016}
\begin{itemize}
    \item Perceived Usefulness
    \item Perceived Ease of Use
    \item E-Learning Self-Efficacy
    \item Perceived Enjoyment
\end{itemize}
\item Spatial reasoning: Measured using the open-source 3D Block Rotation scale from the International Cognitive
Ability Resource (ICAR) \citep{young2025}
